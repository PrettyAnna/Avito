## Установка и запуск

1. Для клонирования репозитория со второй домашней работой воспользуйтесь следующими командами:

   ```bash
   git clone -b hw-2-final https://github.com/PrettyAnna/Avito.git
   cd avito-homework
   ```

## Установка виртуального окружения

Создайте виртуальное окружение в папке проекта. Выполните следующую команду в терминале:
```bash
python -m venv venv
```

Активируйте виртуальное окружение:
- Если Windows:
  ```bash
  venv\Scripts\activate
  ```
- Если Linux или MacOS:
  ```bash
  source venv/bin/activate
  ```
