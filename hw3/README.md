# Домашнее задание №

## Структура проекта

 `ДЗ_3.ipynb` - Основной ноутбук: обработка данных, анализ, выводы 
 `laureates.json` - Исходные данные 
 `laureates_configs.py` - Конфиги обработки лауреатов: людей и организаций 
 `prizes_configs.py` - Конфиг обработки премий у лауреата 
 `json_dict_processing.py` - Универсальный обработчик вложенного словаря по конфигу 
 `dataset_helpers.py` - Общие функции: фильтрация, group_by, агрегации 
 `aggregations.py` - Среднее, медиана, min/max, топ-N по метрике 
 `atribute_manager.py` - Добавление и удаление полей у записей 
 `eda_utils.py` - Вспомогательные функции для EDA (подсчёт пропусков, id-проверки) 

## Требования и зависимости

Для работы скриптов и проверки качества кода требуется **Python 3.10+**. 
В проекте не используются линтеры.
Из стандартной библиотеки используются: json, statistics.

## Установка виртуального окружения

Создайте виртуальное окружение в папке проекта. Выполните следующую команду в терминале:
```bash
python -m venv venv
```

Активируйте виртуальное окружение:
- Если Windows:
  ```bash
  venv\Scripts\activate
  ```
- Если Linux или MacOS:
  ```bash
  source venv/bin/activate
  ```
